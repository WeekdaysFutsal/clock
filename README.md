# 스탠바이 (FoldStandby)

갤럭시 Z 폴드를 세워두었을 때 탁상시계처럼 쓰는 앱입니다.
시계 4종(접이·바늘·달력·타이머), 알람 등록, 날씨, 야간 모드, 세워두면 자동으로 켜기를 담았습니다.

## 1. GitHub에 올려 APK 만들기

1. GitHub에서 새 저장소를 만듭니다. 비공개(Private)를 권합니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 **안의 내용 전체**를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `.github` 폴더와 `.gitignore` 파일도 함께 올라가야 합니다. 맥에서는 Finder에서 `Cmd + Shift + .`을 눌러야 보입니다.
   - `.github` 폴더가 올라가지 않았다면 **Add file → Create new file**에서 파일 이름에 `.github/workflows/build.yml`을 입력하고, 같은 이름 파일의 내용을 붙여 넣으면 됩니다.
3. **Actions** 탭에서 "APK 빌드"가 도는 것을 확인합니다. 보통 3~5분 걸립니다.
4. 끝나면 저장소 오른쪽 **Releases**에 `FoldStandby_Ver.버전_날짜.apk`가 올라옵니다. Releases에 없으면 Actions 실행 결과 맨 아래 **Artifacts**에서 받을 수 있습니다.

이후에는 파일을 고쳐 올릴 때마다 새 APK가 자동으로 만들어집니다.

## 2. 휴대폰에 설치

1. 휴대폰 브라우저로 저장소의 Releases에 들어가 APK를 내려받습니다(비공개 저장소는 GitHub 로그인이 필요합니다).
2. 내려받은 파일을 열고, "출처를 알 수 없는 앱 설치"를 묻는 화면이 나오면 허용합니다.
3. 새 버전은 기존 앱 위에 그대로 덮어 설치됩니다.

## 3. 처음 한 번 설정

- **세워두면 자동으로 켜기**: 앱 화면을 탭 → 오른쪽 조절 아이콘(설정) → 스위치를 켜고, 안내에 따라 '다른 앱 위에 표시' 권한을 허용합니다. 그 뒤에는 잠금 화면이 켜진 상태에서 휴대폰을 벌려(약 20~150도) 세워두면 1~2초 뒤 스탠바이가 뜹니다. 화면이 꺼져 있으면 측면 버튼이나 화면 두드리기로 잠금 화면을 한 번 켜 주세요. 잠금 화면을 '없음'으로 쓰는 경우에는 동작하지 않습니다.
- **텐트처럼 세워 커버 화면으로 볼 때**: 휴대폰 설정 → 디스플레이 → "커버 화면에서 앱 계속 사용"에서 스탠바이를 켜 두면, 펼친 화면에서 접어 세울 때도 화면이 이어집니다(메뉴 이름은 One UI 버전에 따라 조금 다를 수 있습니다).
- **충전기를 연결하면 켜기**: 설정에서 따로 켤 수 있습니다.

## 4. 사용법

- 화면을 **탭**하면 아래에 메뉴가 나옵니다. **옆으로 밀면** 시계가 바뀝니다.
- 알람 표시를 누르면 알람을 맞출 수 있습니다. 알람은 휴대폰 기본 시계 앱에 등록되므로 스탠바이를 닫아도 울립니다.
- 가운데 이음선은 초를 나타냅니다. 1분 동안 차오르고, 분이 바뀌면 숫자 면이 접혔다 펴집니다.
- 야간 모드 '자동'은 주변이 어두워지면 화면을 붉고 어둡게 바꿉니다.

## 5. 고치고 싶을 때

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| 화면 디자인, 시계 종류, 문구, 색 | `app/src/main/assets/index.html` |
| 잠금 화면 표시, 센서, 알람 등록 | `app/src/main/java/app/foldstandby/MainActivity.java` |
| 세워두면 자동으로 켜는 조건(각도·대기 시간) | `app/src/main/java/app/foldstandby/AutoLaunchService.java` |
| 버전 숫자 | `app/build.gradle`의 `versionName` |

`index.html`은 PC 브라우저에서 바로 열어 미리 볼 수 있습니다(휴대폰 기능은 미리보기용 값으로 대신 동작합니다).
AI에게 수정을 맡길 때는 이 파일 하나만 주면 화면 대부분을 바꿀 수 있습니다.

## 6. 알아둘 점

- 타이머 소리는 스탠바이 화면이 떠 있는 동안에만 울립니다. 꼭 울려야 하는 알림은 알람으로 맞추세요.
- 화면을 계속 켜 두는 앱이라 배터리를 씁니다. 오래 세워둘 때는 충전하면서 쓰는 편이 좋습니다. 번인을 줄이려고 2분마다 화면 전체를 몇 픽셀씩 옮깁니다.
- `keystore/foldstandby.p12`는 덮어 설치를 위해 매번 같은 서명을 쓰려고 넣어 둔 개인용 키입니다. 비밀번호가 `app/build.gradle`에 그대로 적혀 있으니, 이 저장소에서 받은 APK만 설치하세요.
- 날씨는 Open-Meteo(https://open-meteo.com)에서 가져옵니다. 숫자 글꼴은 Poppins·Inter(SIL Open Font License)와 TeX Gyre Adventor(GUST Font License)이며 라이선스 전문은 `app/src/main/assets/fonts-license.txt`에 있습니다.
