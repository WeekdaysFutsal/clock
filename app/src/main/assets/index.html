알람 맞추기

    :

    알람은 휴대폰 기본 시계 앱에 등록되어, 스탠바이를 닫아도 울립니다. 잠금 화면에서는 잠금을 푼 뒤 등록됩니다.

    설정

    에디션

    화면 테마블루 에디션은 파랑·하양·빨강 화면에 경기 일정과 매치데이 화면을 더합니다.
    로고 이미지
    배경 이미지
    배경 배치모서리를 고르면 이미지를 크게 키워 그쪽에 붙이고, 화면 밖으로 넘치는 부분은 잘라 일부만 보여 줍니다.
    배경 크기
    배경 진하기
    경기 일정 낱말캘린더 일정 제목에 이 낱말이 들어 있으면 경기로 표시합니다. 쉼표로 나눠 여러 개를 적을 수 있습니다. 제목에 ‘홈’이나 ‘원정’이 있으면 함께 표시합니다.

    시계

    시간 표시
    숫자 모양
    플립 카드 색플립 시계에서 카드를 눌러도 바뀝니다.
    강조색
    초 표시
    야간 모드주변이 아주 어두워지면 어느 화면이든 내용을 붉은색으로만 표시합니다.
    화면 밝기

    날씨

    날씨 지역
    날씨 애니메이션날씨 풍경의 구름·비·눈이 움직입니다. 끄면 배터리를 덜 씁니다.
    미세먼지 표시

    일정

    캘린더 일정 표시
    일정 10분 전 알림화면 위쪽에 일정 이름을 잠깐 띄웁니다.
    아침에는 일정 화면으로오전 6시에 일정 화면으로, 9시에 시계 화면으로 바꿉니다.

    세워둘 때

    바깥 화면에 시계 표시
    바깥 화면 방향가로로 세웠는데 시계가 거꾸로 보이면 ‘가로 반대’를 고르세요.
    무드등시계가 바깥 화면에 뜨는 동안 안쪽 화면을 조명으로 씁니다.
    무드등 색
    날씨에 맞춘 무드등 색맑으면 따뜻한 빛, 비가 오면 푸른빛으로 바꿉니다.
    무드등 밝기
    기상등알람 15분 전부터 무드등이 서서히 밝아집니다.
    세워두면 자동으로 켜기
    잠금이 풀려 있을 때도 켜기살짝 벌려 가로로 세운 채 가만히 두면 켜집니다. 세워서 영상 같은 다른 앱을 볼 때는 꺼 두세요.
    들거나 옮기면 닫기세워둔 휴대폰을 들거나 들고 움직이면 스탠바이를 닫고 원래 휴대폰 화면으로 돌아갑니다. ‘세워두면 자동으로 켜기’를 켜 두었다면 다시 세워둘 때 다시 켜집니다.
    충전기를 연결하면 켜기잠금 상태에서 충전을 시작하면 스탠바이가 켜집니다.
    권한이 필요합니다자동으로 켜려면 ‘다른 앱 위에 표시’ 권한을 허용해야 합니다.
